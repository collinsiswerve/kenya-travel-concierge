KENYA TRAVEL CONCIERGE — MANUAL GITHUB UPLOAD

This ZIP contains the complete finished website: 16 HTML pages, ten dedicated
service pages, images, fonts, styles, JavaScript, and editable source files.
The original website files are unchanged.

UPLOAD USING YOUR BROWSER

1. Download Kenya_Travel_Concierge_Website.zip to your computer.
2. In Windows File Explorer, right-click the ZIP and choose Extract All.
3. Open the extracted folder. You should see README.md, package.json and
   the folders dist, data, docs and scripts.
4. Sign in to GitHub using your normal account and open:
   https://github.com/collinsiswerve/kenya-travel-concierge
5. Select the Code tab and ensure the branch is main.
6. Above the file list, select Add file, then Upload files. Direct link:
   https://github.com/collinsiswerve/kenya-travel-concierge/upload/main
7. From the extracted folder, select the contents and drag them into the
   GitHub upload area. Drag the folders along with the files to preserve
   their internal structure. Do not upload the ZIP itself or its outer folder.
   README.md and dist must appear at the repository's top level.
8. Wait until every file finishes uploading.
9. Enter the commit message: Add complete Kenya Travel Concierge website
10. Select Commit directly to the main branch, then click Commit changes.
    If GitHub requires a new branch, choose Create a new branch, click
    Propose changes, create the pull request, then merge it into main.
11. After committing, confirm the repository shows dist, data, docs, scripts,
    README.md and package.json at the top level. Open dist/index.html in the
    repository to confirm the homepage file is present.

All website files fit GitHub's browser upload limits (100 files per batch,
25 MiB per file). You do not need a key or token for this browser upload.
Optional hidden files .gitignore and .openai/hosting.json are included in the
complete source export; they are not needed to run the site on another host.
This guide itself may be uploaded or left on your computer.

WHAT EACH FOLDER CONTAINS

dist       Ready-to-host website: homepage, service pages, images and fonts.
data       Service descriptions used when regenerating the website.
scripts    Python build and validation scripts; not needed by website visitors.
docs       Existing homepage preview image.
README.md  Editing, hosting, and enquiry details.

UPLOADING AND HOSTING

Committing the files stores the website on GitHub. Publishing a public website
is a separate hosting step. A static host should serve the dist folder.
The original site uses domain-root links. The default GitHub project Pages
address ending /kenya-travel-concierge/ needs a path adjustment or a custom
domain before all navigation and assets will work. Simply enabling Pages
from the repository root will not publish this dist-based layout correctly.

The enquiry form prepares a WhatsApp or email message for the visitor to
review and send; it does not store enquiries in a database.

Official GitHub upload instructions:
https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
